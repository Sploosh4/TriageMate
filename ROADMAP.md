## 10. WINDOWS HOSTING REQUIREMENTS

To run on someone else's Windows laptop for the pitch:

| Requirement | Details |
|---|---|
| **Python** | 3.10+ installed, added to PATH |
| **Git** | Or copy the folder via USB |
| **Steps** | `python -m venv venv` → `venv\Scripts\activate` → `pip install -r requirements.txt` → `cd backend` → `python seed_data.py` → `uvicorn main:app --reload --host 0.0.0.0` |
| **Access** | Open `http://localhost:8000` in browser |
| **ML libraries** | `torch`, `sentence-transformers`, `xgboost` may need special handling on Windows. Recommend `pip install torch --index-url https://download.pytorch.org/whl/cpu` for CPU-only |
| **Cloud vs local** | Windows local works fine. If hosting on a cloud VM, same steps + open port 8000 in firewall |
