# Archived Files

## GitHub Workflow

Follow `github-basics`: only the user creates the task workspace through OpenCode; use its existing shared worktree and branch, and never create or switch workspaces, worktrees, or branches or use a manual/CLI fallback. This skill does not authorize repository or GitHub mutations.

Archived files are preserved for history. Do not modify. Reference `archive/github-migration/MIGRATION-MANIFEST.md` for migration context.
