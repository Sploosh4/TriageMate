## Phase 2 — Python 3.12 dependency compatibility

### 2.1 Update dependency pins

**File:** `backend/requirements.txt`

Change:
```
scikit-learn==1.4.0  →  scikit-learn>=1.4.1.post1,<2.0.0
```

### 4.1 Fix `test_alembic_head_applied` path issue

**File:** `backend/tests/test_alembic.py`

**Issue:** The test has a hardcoded absolute path in the `cwd=` parameter that doesn't exist in CI:
```python
cwd="/home/jpc/Documents/Cybersecurity (Temp)/TriageMate/TriageMate MVP/backend",
```

**Fix:** Replace with a dynamic path derived from the test file's location:
```python
from pathlib import Path

def test_alembic_head_applied(self):
    import subprocess, sys
    # Use the test file's parent directory as cwd — works in CI and locally
    test_dir = Path(__file__).resolve().parent.parent  # points to backend/
    alembic_ini = test_dir / "alembic.ini"
    if not alembic_ini.exists():
        pytest.skip("Alembic config not available in this environment")
    result = subprocess.run(
        [sys.executable, "-m", "alembic", "current"],
        capture_output=True, text=True,
        cwd=str(test_dir),
    )
    assert result.returncode == 0
    assert "009" in result.stdout
```
