## Phase 2: Gated Bug Hunt Loop

**Max iterations:** 3 (if still finding bugs after 3, flag to user)
**Goal:** Find and fix code bugs missed in Phase 1.

### Loop Structure

```
Round N (N = 1, 2, or 3):

1. Run automated audit suite:
   just audit-all        # Calibration, EPSS, features, schema
   just test             # Full test suite
   just lint             # Ruff check
   python -m scripts.verify_seed_scores  # Score contract

2. If any audit/test/lint fails:
   └─ Identify root cause
   └─ Fix the bug
   └─ Go to Round N+1 (if N < 3)

3. If all automated checks pass:
   └─ Run manual bug sweep (see checklist below)

4. If manual sweep finds bugs:
   └─ Fix them
   └─ Go to Round N+1 (if N < 3)

5. If manual sweep finds nothing:
   └─ Phase 2 complete
```

### Manual Bug Sweep Checklist

1. **Context multiplier edge cases** — Test with:
   - `telemetry_threat_score=0`, `vulnerable_code_loaded=None` → multiplier=1.00
   - `telemetry_threat_score=10`, `vulnerable_code_loaded=True` → multiplier=1.20
   - `telemetry_threat_score=5`, `vulnerable_code_loaded=False` → multiplier=1.00 (no active threat if threat < threshold? Actually need to check the logic)
   - Missing `process_evidence` key in telemetry dict → should not crash
   - `confirmed_mitigated=True` + `confirmed_false_positive=True` → FP wins (0.70)

2. **Import hygiene** — Grep for removed import paths:
   ```bash
   rg "from ml.xgboost_predictor import CWE_EPSS_THRESHOLDS" backend/
   rg "from pipeline.tier_2 import" backend/
   rg "SECURITY_CONTEXT_MAX" backend/
   ```
   
3. **DEPRECATED field safety** — Verify no code reads `security_context` as a live dimension:
   ```bash
   rg "security_context" backend/ --include="*.py" | grep -v "0  # DEPRECATED" | grep -v "test_" | grep -v "vestigial"
   ```
   
4. **Score contract consistency** — Spot-check 2–3 CVEs manually:
   ```bash
   cd backend && python -c "
   from scoring import calculate_final_score
   # ... manually verify one CVE from seed data
   "
   ```

5. **Frontend/API contract** — Verify API response shape:
   ```bash
   curl -s http://localhost:8000/api/cases/CVE-2023-34362 | python -c "
   import json, sys
   d = json.load(sys.stdin)
   assert 'contextMultiplier' in d, 'Missing contextMultiplier'
   assert 'securityContext' not in d.get('dimensions', {}), 'securityContext still in dimensions'
   print('API contract OK')
   "
   ```

6. **Feature parity** — Run `just audit-features` — verify inference vs training feature columns match

7. **Ping the drift endpoints** — Quick smoke test:
   ```bash
   curl -s http://localhost:8000/api/drift | python -c "import json,sys; d=json.load(sys.stdin); print('OK' if 'drift' in d else 'FAIL')"
   ```

### Termination Condition

- **Round 1**: If any bugs found and fixed → Round 2
- **Round 2**: If any bugs found and fixed → Round 3
- **Round 3**: If any bugs found and fixed → **flag to user**: "Bug hunt found issues in all 3 rounds. Remaining: [list]. Continue or defer?"
- **Any round with zero bugs found**: Phase 2 complete.

**Gate:** Two consecutive clean runs of all audit tools (automated + manual) with zero issues found.
