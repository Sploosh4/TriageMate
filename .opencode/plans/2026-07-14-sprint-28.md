## Item 2: Phase 7.6 — Scoring Weight Zero Policy Decision (✅ Complete)

**Bug:** FE-LOW-3
**Files:** `adminSettings.js`, `scoring.py`, `admin.py`

**Decision:** Zero is NOT supported — retain minimum of 1.
**Rationale:** Each weight dimension represents a meaningful factor; setting to zero would silently remove a dimension. If an organization wants to exclude a dimension, the scoring model should be reconfigured, not zero-weighted.
**Actions taken:** Documented in `docs/architecture/weight-zero-decision.md`. No code changes needed — backend already enforces min=1, slider already starts at 1.
