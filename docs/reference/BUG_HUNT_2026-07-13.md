### CORE-CRIT-1: PG context manager returns wrong object
| Field | Value |
|---|---|
| **File** | `backend/database.py` |
| **Line** | 159–160 |
| **Severity** | **CRITICAL** |
| **Category** | API contract violation |
| **Description** | `_PGConnection.__enter__` returns `self._conn.__enter__()` — the raw psycopg2 connection, not the wrapper. Any code using `with get_db() as c:` on PostgreSQL gets a raw connection without the `execute()` shortcut, and cursor operations return raw tuples instead of `_PGCompatRow` dict-like objects. Currently latent because all callers use `with conn:` (no `as` clause), but this is a ticking bomb. |
| **Fix** | Change to `return self`: `__enter__` should start the transaction on the raw connection but return the wrapper. |

### CORE-HIGH-2: Race condition on CWE lookup cache
| Field | Value |
|---|---|
| **File** | `backend/ingest_cwe.py` |

| **Severity** | **HIGH** |

### CORE-HIGH-3: Bare `except Exception: pass` swallows all ALTER TABLE errors
| Field | Value |
|---|---|
| **File** | `backend/database.py` |
| **Line** | 557–580 |
| **Severity** | **HIGH** |
| **Category** | Exception handling |

### CORE-HIGH-4: Scheduler retrain lock has TOCTOU race condition
| Field | Value |
|---|---|
| **File** | `backend/scheduler.py` |
| **Line** | 53–70, 279–285 |
| **Severity** | **HIGH** |
| **Category** | Race condition |
| **Description** | `_is_lock_held()` reads the lock file's existence/age, then `_acquire_lock()` creates it — the check and creation are not atomic. | **Fix** | Use `LOCK_FILE.open("x")` (exclusive creation fails if exists) to atomically acquire the lock. Wrap in try/except `FileExistsError`. |
