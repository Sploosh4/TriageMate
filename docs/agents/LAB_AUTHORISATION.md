# Existing private test authority

The self-hosted refactor does not revoke previously granted, narrowly scoped private test-environment authority. Original authorization and identity/evidence references remain in preserved private local storage; obsolete repository history is no longer a recovery source. This note is not authorization for a new environment, broader collection or device changes.

Before any private test action, establish the applicable direct user authorization and verify the intended tenant/device/host identity. Keep evidence, identifiers and credentials in their existing ignored private locations. Do not publish, relocate or delete them as part of this refactor. Do not contact others or activate broader persistent schedules without applicable authorization.

Repository acceptance remains synthetic/public and does not require private test credentials. Product patch execution and device changes remain out of scope. Current deployment uses the [container guide](../guides/CONTAINERS.md).
