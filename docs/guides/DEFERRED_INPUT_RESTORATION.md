# Input restoration boundaries

The container refactor preserves supported input contracts but does not restore retired collectors. Source registry presence, historical evidence and archived code do not enable a source or recurring schedule. Reopening requires a selected source, purpose, supported identity/schema contract, permission/license checks and direct regression evidence.

Deferred Microsoft inputs are Entra users, groups, direct memberships, enterprise app assignments and Defender raw activity/Advanced Hunting. Their possible value does not establish business ownership, installed software or observed exploitation. Deferred public collection includes Cisco, Palo Alto Networks, Red Hat, Ubuntu, Debian, Apache HTTP Server/Tomcat, Samba, GitHub Advisory Database, OSV, Exploit-DB, CTID mappings, MITRE ATT&CK and historical EPSS archive backfill. Current dated EPSS remains distinct from archive backfill.

Parsers, reference records, replay readers, schema/read support and helpers may remain because supported inputs or retained evidence depend on them. Do not delete shared code just because a collector is deferred. No patch execution, custom scoring, Queue/Case, Nessus, Network visualization, Copilot, Sentinel or full CMDB is restored.

Obsolete recovery branches, tags and product history have been removed. Some retained metadata names the historical source revisions that defined a contract; these identifiers are provenance rather than available recovery snapshots. Do not rely on removed tags or assume historical code is present.

Any future implementation must start from the selected retained contract and current upstream documentation. Integrate it into current collection, receipt, persistence and query interfaces only after renewed scope approval. Revalidate pagination/completeness, replay, idempotency, cancellation/rollback and authority. Keep private evidence and credentials outside Git.

Tool research is in [Microsoft collectors](../research/MICROSOFT_COLLECTORS.md) and [public feeds](../research/PUBLIC_FEEDS.md). New tools still require evidence contracts and do not silently reopen all deferred sources.
