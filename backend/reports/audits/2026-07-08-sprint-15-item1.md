### Item 3 — PSI Computation
- **Formula:** `compute_psi()` implements the standard PSI formula:
  ```
  PSI = Σ (actual_pᵢ − expected_pᵢ) × ln(actual_pᵢ / expected_pᵢ)
  ```
- **Edge cases:**
  - `expected_p == 0.0`: Bin is skipped (contributes 0) ✅
  - `actual_p == 0.0`: Replaced with `EPSILON = 0.0001` to avoid log(0) ✅
  - Empty input (`total_actual == 0`): Returns 0.0 ✅
- **Drift status thresholds** in `_get_drift_status()`:
  - `psi < 0.1` → "stable"
  - `0.1 ≤ psi < 0.25` → "warning"
  - `psi ≥ 0.25` → "critical"
- **Tests:** All 14 passed (file: `backend/tests/test_drift_ml.py`)
- **Manual verification:**
  - Identical distributions → PSI = 0.0 ✅
  - Shifted distribution → PSI = 4.604318 (math verified) ✅
  - Zero expected bin → PSI = 0.0 (skips zero bin) ✅
  - Empty actual → PSI = 0.0 ✅
