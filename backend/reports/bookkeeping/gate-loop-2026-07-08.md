- **File:** `backend/ml/model_registry.json`
- **Expected from:** Sprint 11 Item 2 ("Model version management")
- **Detail:** The model version registry file referenced by both `backend/routers/models.py` (line 16: `REGISTRY_PATH = Path(__file__).resolve().parent.parent / "ml" / "model_registry.json"`) and `backend/ml/xgboost_predictor.py` (line 26: `REGISTRY_PATH = Path(__file__).parent / "model_registry.json"`) does **not exist anywhere on disk**.
- **Impact:** 
  - `GET /api/model/versions` returns empty versions array

  - **Inference still works** — predictor falls back to default paths (`xgboost_model.pkl`, `xgboost_calibrator.pkl`)

- **Recommendation:** Create `backend/ml/model_registry.json` with entries for the 3 models (see Sprint 11 plan for schema), or verify if it was deleted accidentally and restore from git history.
